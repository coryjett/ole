# Getting started with Ole

You need a Mac (Apple Silicon), an **MCP server** address and key, and an **OpenAI key** (or your own model server).

1. **Install.** Download the `.dmg` from [Releases](https://github.com/coryjett/ole/releases), drag Ole to Applications, open it. If macOS blocks it: **System Settings › Privacy & Security › Open Anyway**.
2. **First run.** Paste your OpenAI key, then allow the microphone, call audio and Accessibility. If asked about **"Ole Safe Storage"**, choose **Always Allow**.
3. **Add your MCP server.** **Settings › Ole › MCP servers › Add server**: name, address, key, **Save**, **Test**. Green means ready.
4. **Prepare.** Ole prepares by itself 10 minutes before calendar meetings, or press **Prepare for next call** on Home. Add a company in **Focus** if you like.
5. **Call.** Start recording when the call starts and tell people you're recording. Context pops up as you talk: 📌 pins one into your notes, 👍/👎 tunes what you get, and **Ask Ole** answers a question.
6. **After.** Stop recording. The summary, transcript and context are saved with the meeting.

Updates install themselves on restart. Stuck? Press **Test** next to the server in Settings. Still stuck? [Open an issue](https://github.com/coryjett/ole/issues).
